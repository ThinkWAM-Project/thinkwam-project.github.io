ThinkWAM: Rethinking Latent Futures
for Action Refinement

arXiv Coming soon GitHub 🤗 Hugging Face { } BibTeX

TL;DR. ThinkWAM proposes an action, rethinks the future it would produce, and refines the action using the corrected future representations.

Abstract

Vision-language-action policies must decide how to act before the consequences of an action are visible. ThinkWAM introduces a proposal–rethink–refine loop that connects action generation with predictions of future visual states. The model uses affordance-guided observation–action memory and multi-horizon latent forecasts to represent the current context and its possible evolution.

An initial action proposal conditions a visual residual predictor that corrects the future latents. A second pass of the shared action head then uses these corrected futures to generate the executable action chunk. The entire process operates in latent space, without decoding future images during control. We evaluate ThinkWAM on LIBERO, LIBERO-Plus, RoboTwin 2.0, and RoboCasa24.

Method

Action-conditioned latent correction between two passes of a shared action model.

1. Propose. Encode observations and executed-action history into affordance-guided memory. The first action pass uses this context, the instruction, and the robot state to propose an action chunk.

2. Rethink. A residual predictor conditions on the proposed action and current visual features to correct latent forecasts at near, middle, and far horizons.

3. Refine. A second pass of the same action head reads the corrected futures and produces the action chunk for execution. The robot observes again after acting.
