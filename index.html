01

Overview

A proposed action should change its predicted future. ThinkWAM feeds the proposal back into latent predictions, then refines the action before execution.

A complete action chunk corrects multi-horizon future latents through a learned residual. The same action head uses these corrected futures in a second pass, supported by affordance-guided memory and near-fine, far-coarse prediction. All prediction stays in latent space.

02

Method

A second action pass, guided by corrected latent futures.

  1. 1Propose

    Use observation–action memory to propose the next action chunk.

  2. 2Rethink

    Correct near, middle, and far latent futures using the proposed action.

  3. 3Refine

    Generate the executable action chunk from the corrected futures.

Architecture details

ThinkWAM uses a proposed action to revise its latent future predictions, then conditions the second action pass on those revised futures. The images used to illustrate latent horizons are conceptual visualizations.
