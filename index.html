01Overview

ThinkWAM proposes an action, rethinks its latent future, and refines the action before execution.

Affordance-guided memory and multi-horizon forecasts support the loop, without decoding future images during control.

02Method

A second action pass, guided by corrected latent futures.

1. ProposeUse observation–action memory to propose the next action chunk.

2. RethinkCorrect near, middle, and far latent futures using the proposed action.

3. RefineGenerate the executable action chunk from the corrected futures.

Architecture details

ThinkWAM uses a proposed action to revise its latent future predictions, then conditions the second action pass on those revised futures. The images used to illustrate latent horizons are conceptual visualizations.
